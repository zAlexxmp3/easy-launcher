## ✨ About

> **Easy Launcher** is a universal game launcher for Windows.
> It auto-detects your games from **Steam** and **Epic Games**,
> fetches beautiful cover art from **SteamGridDB**,
> and keeps everything in one clean, minimal interface.

**No more switching between launchers.**
**Everything you play — in one place.**
